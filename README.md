# Получение курсов валют через Saloon

## Стек
- Laravel 13
- Saloon 4

## Структура проекта
```
Action/ - действия (Actions)
Console/ - консольные команды
Enum/ - общие для проекта ENUM
Http/
    Controllers/ - контроллеры
    Middleware/ - middleware
    Request/ - объекты-обёртки для Request
Job/ - общие джобы + абстракция
Models/ - модели
Module/ - папки модулей
    ExchangeRate/ - модуль обмена валют
        Api/ - обёртки для работы с API сервисов работы с данными обмена валют. Должно содержать класс-коннектор и запрос данных. Тут используется Saloon
        Dto/ - DTO для модуля
        Enum/ - ENUM для модуля
        Exception/ - спец. классы исключений
        Job/ - queue для работы с добавлением записей в таблицу
        Repository/ - специальные репозитории для обмена валют
        Service/ - сервис для обмена валют
    Queue/ - модуль работы с очередями. Не вынесено в общую папку 'Job', потому что здесь сейчас имеется только обёртка для RabbitMQ
Providers/ - провайдеры
Repository/ - абстракция для репозиториев. Сейчас только пустой интерфейс
helpers.php - helper функции
```
